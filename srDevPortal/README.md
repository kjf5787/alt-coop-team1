# Senior Dev Self Assessment Portal 

## Description 
This project is a web application that allows senior development class students to self-assess their skills. 
It features a dynamic form for answering questions and an admin portal for viewing student results.

## Features/Accomplishments
- Login with email verification via an OTP code
- Dynamic assessment form that loads questions from the DB 
- Assessment form pre-fills previous answers and validates inputs before submission
- Admin portal that fetches student responses and enables filtering and sorting
- Session management that logs out user after 1 hour of inactivity 
- Admin access is controlled via config/config.php, which contains a list of authorized admin emails
